# Focus Session - Quick Reference Card

## 🎯 Getting Started

1. **Navigate to Focus Page**: `/focus-new`
2. **Select or Create Task**: Type in the task input box
3. **Choose Mode**: Focus (25 min) | Short Break (5 min) | Long Break (15 min)
4. **Press Play**: Start your focus session
5. **Work Without Distractions**: Stay focused until the timer ends

---

## ⚡ Quick Actions

### Main Controls

- **Play/Pause Button** (Large circle): Start or pause the timer
- **Reset Button** (Small circle): Reset timer to original duration
- **Mode Buttons**: Switch between Focus, Short Break, Long Break

### Task Management

- **Continue Last Task**: Click the blue card to resume your previous task
- **Type to Search**: Start typing to find existing tasks
- **Create New**: Type a new task name and select "Create: [name]"
- **Clear Input**: Click the X icon to clear task selection

### View Controls

- **Toggle Stats** (📊): Show/hide productivity statistics
- **Settings** (⚙️): Open preferences and customization
- **Exit** (✕): Close focus session and return to dashboard

---

## 🎨 Visual Indicators

### Timer Colors

- **Indigo/Purple**: Focus mode (deep work time)
- **Green**: Short break (5-minute rest)
- **Purple**: Long break (15-minute rest)

### Progress Indicators

- **Circular Ring**: Shows remaining time visually
- **Session Bars**: Progress toward long break
- **Percentage Ring**: Daily goal completion

### Session Status

- **Pulsing Effect**: Timer is currently running
- **Completed Checkmarks**: Sessions finished today
- **Task Cards**: Show focus statistics (sessions · minutes)

---

## ⚙️ Customization Options

### Timer Settings

- **Focus Duration**: 15-60 minutes (default: 25)
- **Sessions Until Long Break**: 2-5 sessions (default: 4)
- **Daily Goal**: Target number of sessions per day

### Sound & Notifications

- **Sound Effects**: Chime, Bell, or None
- **Volume**: 0-100% adjustable
- **Browser Notifications**: Enable/disable
- **Auto-start**: Automatically begin breaks or focus sessions

### Personal Preferences

- **Theme**: Light, Dark, or System preference
- All settings auto-save to your account

## 🎓 Focus Session Tips

### Before Starting

- ✅ Choose ONE specific task
- ✅ Clear your workspace
- ✅ Close unnecessary tabs/apps
- ✅ Turn off phone notifications
- ✅ Have water nearby

### During Focus

- ✅ Stay on your selected task
- ✅ Ignore distractions (write them down for later)
- ✅ Don't check email/messages
- ✅ If interrupted, pause the timer

### During Breaks

- ✅ Step away from your desk
- ✅ Stretch or walk around
- ✅ Hydrate and breathe deeply
- ✅ Avoid screens if possible (especially long breaks)

### After Completion

- ✅ Review what you accomplished
- ✅ Update task status if needed
- ✅ Plan next focus session
- ✅ Celebrate your progress! 🎉

## 💡 Pro Tips

### Maximize Productivity

1. **Set a daily goal**: Track progress toward a specific number of sessions
2. **Use task estimates**: Break large projects into 2-4 session chunks
3. **Review your stats**: Check which tasks took most time
4. **Find your rhythm**: Notice your best focus times

### Handle Interruptions

- If interrupted **briefly** (< 1 min): Continue the session
- If interrupted **significantly**: Pause timer, return later
- If can't continue: Reset and mark as interrupted

### Task Management

- Use **specific task names**: "Write intro paragraph" vs "Essay"
- Link to **existing tasks**: Track focus time per assignment
- Create **ad-hoc tasks**: Quick sessions without formal task creation

### Stay Motivated

- Celebrate your **current streak**: Keep the momentum going
- Review **completed tasks**: See your daily accomplishments
- Share **stats** (future): Compete with friends (opt-in)

## 🐛 Troubleshooting

### Timer Not Starting?

- Ensure you clicked the play button (large circle)
- Check browser console for errors
- Refresh the page if needed

### No Sound Playing?

- Check sound is enabled in settings
- Verify volume is not at 0
- Test your browser audio settings

### Notifications Not Showing?

- Allow browser notification permission (click "Allow")
- Check system Do Not Disturb is off
- Verify notifications enabled in settings

### Task Not Saving?

- Ensure you're logged in
- Check internet connection
- Try creating task again

### Stats Not Updating?

- Refresh the page
- Toggle stats view off and on
- Check database connection
